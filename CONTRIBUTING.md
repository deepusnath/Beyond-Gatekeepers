# Contributing to Beyond Gatekeepers

This repo runs on the same rule as the meetups: **contribution is the currency.** Here's how to spend yours.

## Ways to contribute (easiest first)

1. **Attend a session.** Genuinely, that's contribution zero and the one that matters most.
2. **Be a scribe.** Log a session using [the template](./templates/session-log-template.md) and PR it to the chapter's `sessions/` folder. Scribes get credit in every log they write.
3. **Improve a playbook.** Ran a session and learned something? Fold it back in. Playbooks here are living documents built from practice, not theory.
4. **Propose a chapter.** Read the [Launch Playbook](./playbooks/launch-a-chapter.md), copy the [charter template](./templates/CHARTER-template.md), open a PR.
5. **Volunteer to co-lead a Forming chapter.** Open an issue with the `chapter-lead` label, or better, show up and say so.

## Pull request guidelines

- Session logs: one file per session, named `YYYY-MM-NN.md`, merged fast (a week-old unlogged session is losing detail by the day, speed beats polish).
- Charter PRs: must use the template with rhythm and both co-leads filled. Reviewed by existing chapter leads within a week.
- Governance/playbook changes: expect open discussion. Changes to the three constitutional rules (fixed rhythm, free entry, no capture) will not be merged, see [GOVERNANCE.md](./GOVERNANCE.md).

## Style

- Write like you'd talk at a session: direct, concrete, generous.
- Real names or consistent handles in logs, credit is the point.
- English is the working language of the repo; session logs may add a local-language summary section.

## Code of Conduct

Everyone participating (in this repo and in every chapter's physical room) is bound by our [Code of Conduct](./CODE_OF_CONDUCT.md).
